## Description of the Assignment
The purpose of this assignment was to learn how to use the if/else if statements. We needed to use the statements correctly to tell Arduino what LED light should be on for n second.
We also needed to be able to correctly time the count using different multiples for the LED lights to only light up a certain light when its specific multiple equals zero.
