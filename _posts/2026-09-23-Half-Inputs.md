# Nested Conditionals
---

## Description of the Assignment
For this assignment, I wrote an Arduino program that uses a button and a switch with two true or false variables, btn and swt. Since two variables give four combinations, I used four colored LEDs, and exactly one lights up for each combo. To test it, I changed the variable values, re-uploaded, and checked each color.

I used logical operators instead of nested conditionals. Each combination fit into a single condition, which kept the code easy to read.


## Tip/Trick for next time
When writing the code remember to have all the lights start out as off so then you have a baseline for when one light needs to turn on.
