## Description of the Assignment
The assignments purpose was to use random PWM pins on Arduino. The program will pick out a pin and if that pin is already on then
the program will turn that LED pin off. It gives the LED a random brightness for each PWM pin. Since the pin numbers are not consecutive the program
picks a random one.
